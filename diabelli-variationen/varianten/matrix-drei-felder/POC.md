# Proof of Concept — fünf Positionen, drei Sätze

Fünfzehn Stücke aus 99. Stand 22.09.2026. Veröffentlichte Fassung: <https://claude.ai/artifact/3a9SsHmUqbXHfyW4JrEB2S>

Die Umwelt ist für alle drei identisch — dieselbe Operation, dieselbe Position im Zyklus. Verschieden ist allein das Material.

---

## I — Umtaktung

*Der Satz gegen seine eigene Betonung gelesen. Aus dem Wiegen wird ein Schritt. Stimme anweisend, Grad A.*

**Literatur**
```
Nicht: fremd bin ich eingezogen.
Sondern: Fremd. Bin. Ich.
Ein-ge-zo-gen.

Und auf den ersten Schlag:
Fremd zieh ich wieder aus.

Nicht traurig. Gezählt.
So hat es immer geheißen.
Ihr habt es nur gesungen.
```

**Politik**
```
Nicht: es ist Ruhe und Ordnung.
Sondern: Ruhe. Und Ordnung.
Ruhe. Und Ordnung.

Und so bleibt es. Auf eins.

So war es gemeint.
Von Anfang an.
```

**Architektur**
```
Nicht: sechs Säulen vorn, zehn zur Seite.
Sondern: Sechs. Vorn.
Zehn. Zur Seite.
Und ein Dach darüber. Auf eins.

Das ist keine Ansicht.
Das ist eine Aufstellung.
```

## XXII — Einschleusung

*Fremdes Material wird ins Gerüst gezwungen und nicht angepasst. Bei Beethoven zitiert diese Variation Leporellos Klage über die Arbeit. Derselbe Eindringling in allen drei Sätzen. Grad B, Politik Grad C.*

**Literatur**
```
Fremd bin ich eingezogen,
Tag und Nacht mich plagen,
fremd zieh ich wieder aus.
```

**Politik**
```
Es ist Ruhe und Ordnung,
und Tag und Nacht mich plagen,
und so bleibt es.

Es ist Ruhe und Ordnung,
es ist Ruhe und Ordnung,
und so bleibt es.
```

**Architektur**
```
Sechs Säulen vorn,
Tag und Nacht mich plagen,
zehn zur Seite, und ein Dach darüber.
```

## XXXIII — Rückzug

*Der Satz zum ersten und einzigen Mal ganz einfach gesagt, leiser werdend. Kein Triumph, kein Fazit. Das Ich spricht, kurz.*

**Literatur**
```
Ich ziehe wieder aus.
Fremd — das war ich beim Einzug auch.

Gute Nacht.
```

**Politik**
```
Ich habe es oft gesagt.

Es ist Ruhe.
```

**Architektur**
```
Ich habe die Säulen nicht gezählt.

Ein Dach darüber.
```

## Belegstatus

Ein gesichertes Zitat (Müller, *Urania* 1823), zwei aus belegten Vorlagen konstruierte Sätze.

Zu prüfen: Müllers Folgezeile „Der Mai war mir gewogen" gegen den Erstdruck von 1823 — die Schubert-Fassung weicht an anderen Stellen ab. Der Eindringling in XXII ist die deutsche Entsprechung zu Leporellos „Notte e giorno faticar"; ob er in dieser Wendung stehen bleibt, ist offen.
