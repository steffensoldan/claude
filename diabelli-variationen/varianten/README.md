# Varianten

Parallele, **unentschiedene** Entwicklungslinien. Weder aktiver Arbeitsstand noch Archiv.

Eine Variante liegt hier, solange offen ist, ob sie verfolgt wird. Wird sie übernommen, wandert sie nach `bauplan/`; wird sie verworfen, nach `archiv/` — mit Begründung, wie für jede abgelöste Stufe.

| Variante | Betrifft | Status |
|---|---|---|
| [`ruhe-und-ordnung/`](ruhe-und-ordnung/) | Kernsatz und Zeitbezug | offen — nicht entschieden, Stand 20.09.2026 |

Der maßgebliche Stand bleibt bis auf Weiteres `bauplan/`.
